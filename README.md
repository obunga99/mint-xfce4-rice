# mint-xfce4-rice
the repo of my linux mint xfce rice

# Installation \
make sure to have git and stow is installed

```bash
#for debian/ubuntu systems, I use linux mint xfce
sudo apt update && sudo apt install stow && sudo apt install git
```

\
then, to install
```bash
git clone https://github.com ~/.dotfiles
cd ~/.dotfiles
stow xfce terminal
```
